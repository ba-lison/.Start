# PRD-001 — CLI de saudação

> propósito: o que a primeira versão entrega, para quem e como comprovar
> ler quando: unidades de plano e de execução que citam este PRD
> atualizar quando: mudança de escopo aprovada pelo usuário (é decisão D-01)
> status: APPROVED
> versao_alvo: 0.1.0
> decisao_aprovacao: DEC-004

## Problema, usuários e valor

Mostrar o processo .start com o menor produto possível, para quem estuda o processo.

## Métricas de sucesso

- v0.1.0 entregue com histórico completo e verificável.

## Requisitos funcionais

- [x] RF-001 — ao receber um nome não vazio, imprimir `Olá, <nome>!`.
- [x] RF-002 — rejeitar nome vazio com mensagem e código de saída diferente de zero.

## Requisitos não funcionais

- N/A — exemplo mínimo.

## Cenários e critérios de aceite

- `cli Ana` imprime exatamente `Olá, Ana!` e sai com código 0.
- `cli ""` imprime uma mensagem de erro e sai com código diferente de 0.

## Fora de escopo

Interface gráfica, rede, persistência e localização (DEC-003).
