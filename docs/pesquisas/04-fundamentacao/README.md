## Regra editorial

Cada relatório distingue:

- **evidência:** conteúdo sustentado por fonte;
- **interpretação:** consequência inferida para este sistema;
- **decisão proposta:** regra ainda sujeita à aprovação humana.

Fontes oficiais e padrões têm precedência. Opiniões industriais são usadas quando não existe norma aplicável. Conteúdo de fornecedores de IA é usado para agentes; não substitui especialistas em Git, testes, segurança ou operações.
