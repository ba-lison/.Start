# Biblioteca de Fundamentação do `.Start`

> Material de consulta e pesquisa que embasou as decisões de engenharia do processo `.Start`. Estes arquivos **não** entram nos projetos de código e **não** são carregados pela skill `start`.

## Estrutura do Acervo

| Pasta | Conteúdo |
| :--- | :--- |
| [`00-embasamento-do-processo/`](./00-embasamento-do-processo/) | Estudos diretos do protocolo: Circuit Breakers anti-loop, padrão Orchestrator-Worker em profundidade 1, Micro-Handoff determinístico, Sprints e esteira de entrega. |
| [`01-memoria-agentes-ia/`](./01-memoria-agentes-ia/) | Arquitetura de memória persistente para agentes de código, Working Context vs. Memory Bank, segurança contra prompt injection em memória e documentação oficial (Anthropic, OpenAI, Google). |
| [`02-build-release-engineering/`](./02-build-release-engineering/) | Builds determinísticas e reproduzíveis, branching, pipelines de CI/CD, promoção de artefatos, versionamento, rollback, migrações de banco, supply chain e métricas DORA. |
| [`03-especificacoes-sdlc/`](./03-especificacoes-sdlc/) | Spec-Driven Development (SDD) com IA, escrita de PRDs orientados a LLMs, documentação técnica e glossário de engenharia de software. |
| [`04-fundamentacao/`](./04-fundamentacao/) | Sínteses executivas das pesquisas e matriz de decisões que originaram os guardrails do kit. |
